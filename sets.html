🎯 Sets in Python

Introduction to Sets

A Set is an unordered collection of unique elements. Sets are useful when duplicate values should not be stored. 

numbers = {10, 20, 30, 40}

print(numbers)

Output

{10, 20, 30, 40}

Characteristics of Sets

  • Sets are unordered collections.
  • Sets do not allow duplicate values.
  • Sets are mutable.
  • Sets are enclosed within curly braces { }.
  • Sets do not support indexing.

Creating Sets

fruits = {"Apple", "Orange", "Mango"}

print(fruits)

Duplicate Values are Removed

numbers = {10,20,10,30,20,40}

print(numbers)

Output

{10, 20, 30, 40}

Creating an Empty Set

s = set()

print(type(s))

Output

<class 'set'>

Adding Elements

numbers = {10,20,30}

numbers.add(40)

print(numbers)

Output

{10, 20, 30, 40}

Removing Elements

numbers = {10,20,30,40}

numbers.remove(20)

print(numbers)

Output

{10, 30, 40}

Traversing a Set

numbers = {10,20,30,40}

for item in numbers:
    print(item)

Important Set Methods

Method Description
add() Add an element
remove() Remove an element
discard() Remove safely
clear() Remove all elements
pop() Remove a random element

Set Operations

Set operations are one of the most important applications of sets. 

A = {1,2,3,4}
B = {3,4,5,6}

1. Union ( | )

Combines all elements from both sets. 

print(A | B)

Output

{1,2,3,4,5,6}

2. Intersection ( & )

Returns common elements. 

print(A & B)

Output

{3,4}

3. Difference ( - )

Returns elements present in first set only. 

print(A - B)

Output

{1,2}

4. Symmetric Difference ( ^ )

Returns elements present in either set but not both. 

print(A ^ B)

Output

{1,2,5,6}

Membership Operators

numbers = {10,20,30,40}

print(20 in numbers)
print(50 in numbers)

Output

True
False

Program 1: Remove Duplicates from List

numbers = [10,20,10,30,20,40]

unique = set(numbers)

print(unique)

Output

{10,20,30,40}

Program 2: Find Common Elements

A = {10,20,30,40}
B = {30,40,50,60}

print(A & B)

Output

{30,40}

Program 3: Student Subjects

science = {"Physics","Chemistry","Maths"}
computer = {"Maths","Computer Science"}

print(science & computer)

Output

{'Maths'}
