🔢 Variables and Data Types

What is a Variable?

A variable is a named memory location used to store data temporarily during the execution of a program. The value stored in a variable can be changed whenever required.

Variables help programmers store and manipulate information such as numbers, names, marks, and calculations.

Creating Variables in Python

In Python, a variable is created when a value is assigned to it using the assignment operator (=). 

x = 10
name = "Rahul"
marks = 95.5

Variable Assignment

Variable Value Stored
x 10
name Rahul
marks 95.5

Rules for Naming Variables

  • Variable names can contain letters, digits and underscore (_).
  • Variable names cannot begin with a digit.
  • Spaces are not allowed.
  • Python keywords cannot be used as variable names.
  • Variable names are case-sensitive.

Valid Variable Names

age = 17
student_name = "Anu"
totalMarks = 450
_count = 25

Invalid Variable Names

2age = 17        # Starts with digit
student name     # Contains space
class = 10       # Python keyword

Case Sensitivity

Python treats uppercase and lowercase letters differently. 

name = "Rahul"
Name = "Anu"

print(name)
print(Name)

Output

Rahul
Anu

What are Data Types?

A data type specifies the type of value stored in a variable. Python automatically identifies the data type based on the assigned value.

Common Data Types in Python

Data Type Description Example
int Integer values 25, 100, -8
float Decimal values 10.5, 98.25
str Text/String values "Python"
bool Logical values True, False

Integer (int)

Integer values are whole numbers without decimal points. 

age = 17
year = 2026

print(age)
print(year)

Float (float)

Float values contain decimal points. 

height = 5.8
price = 125.50

print(height)
print(price)

String (str)

Strings are sequences of characters enclosed within quotation marks. 

name = "Python"
city = "Kollam"

print(name)
print(city)

Boolean (bool)

Boolean values represent logical conditions. 

isStudent = True
isPassed = False

print(isStudent)
print(isPassed)

Checking Data Type Using type()

The type() function is used to identify the data type of a variable. 

x = 10
y = 12.5
name = "Python"

print(type(x))
print(type(y))
print(type(name))

Output

<class 'int'>
<class 'float'>
<class 'str'>

Type Conversion

Type conversion means changing one data type into another. 

x = "25"

num = int(x)

print(num)
print(type(num))

Output

25
<class 'int'>

Real-Life Example

student = "Arun"
age = 17
mark = 95.5
passed = True

print(student)
print(age)
print(mark)
print(passed)

Program Explanation

  1. student stores a string value.
  2. age stores an integer value.
  3. mark stores a float value.
  4. passed stores a boolean value.
  5. All values are displayed using print().
