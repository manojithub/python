Introduction

The Program Library contains frequently asked Python programs that are important for examinations, practical records and programming practice. Students should understand the logic, algorithm and output of each program.

Program 1: Check Even or Odd Number

num = int(input("Enter a Number: "))

if num % 2 == 0:
    print("Even Number")
else:
    print("Odd Number")

Output

Enter a Number: 12
Even Number

Program 2: Find Largest of Two Numbers

a = int(input("Enter First Number: "))
b = int(input("Enter Second Number: "))

if a > b:
    print("Largest =", a)
else:
    print("Largest =", b)

a = int(input("Enter First Number: "))

c = int(input("Enter Third Number: "))

if a > b and a > c:
    print(a)

    print(b)

    print(c)

Program 4: Check Prime Number

num = int(input("Enter Number: "))

flag = True

if num <= 1:
    flag = False

for i in range(2, num):
    if num % i == 0:
        flag = False
        break

if flag:
    print("Prime Number")
else:
    print("Not Prime Number")

Program 5: Multiplication Table

num = int(input("Enter Number: "))

for i in range(1,11):
    print(num, "x", i, "=", num*i)

Program 6: Factorial of a Number

num = int(input("Enter Number: "))

fact = 1

for i in range(1, num+1):
    fact *= i

print("Factorial =", fact)

Output

Enter Number: 5
Factorial = 120

Program 7: Fibonacci Series

n = int(input("How Many Terms: "))

a = 0
b = 1

for i in range(n):
    print(a, end=" ")
    c = a + b
    a = b
    b = c

Output

0 1 1 2 3 5 8 13

Program 8: Reverse a Number

num = int(input("Enter Number: "))

rev = 0

while num > 0:
    digit = num % 10
    rev = rev * 10 + digit
    num = num // 10

print("Reverse =", rev)

Program 9: Palindrome Number

num = int(input("Enter Number: "))

temp = num
rev = 0

while num > 0:
    digit = num % 10
    rev = rev * 10 + digit
    num = num // 10

if temp == rev:
    print("Palindrome")
else:
    print("Not Palindrome")

Program 10: Armstrong Number

num = int(input("Enter Number: "))

temp = num
total = 0

while num > 0:
    digit = num % 10
    total += digit ** 3
    num = num // 10

if temp == total:
    print("Armstrong Number")
else:
    print("Not Armstrong Number")

Program 11: Sum of Digits

num = int(input("Enter Number: "))

total = 0

while num > 0:
    total += num % 10
    num = num // 10

print("Sum =", total)

Program 12: Count Vowels in a String

text = input("Enter String: ")

count = 0

for ch in text.lower():
    if ch in "aeiou":
        count += 1

print("Vowels =", count)
