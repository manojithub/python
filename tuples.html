📦 Tuples in Python

Introduction to Tuples

A Tuple is an ordered collection of elements similar to a list. However, unlike lists, tuples are immutable, which means their elements cannot be modified after creation.

Tuples are used when data should remain constant throughout the program. 

numbers = (10, 20, 30, 40)

print(numbers)

Output

(10, 20, 30, 40)

Characteristics of Tuples

  • Tuples are ordered collections.
  • Tuples are immutable.
  • Tuples allow duplicate values.
  • Tuples can contain different data types.
  • Tuples are enclosed within parentheses ( ).

Creating Tuples

t1 = (10, 20, 30)
t2 = ("Apple", "Orange", "Mango")
t3 = (10, "Python", 25.5)

print(t1)
print(t2)
print(t3)

Creating a Single Element Tuple

A comma is mandatory when creating a single-element tuple. 

t = (10,)

print(type(t))

Output

<class 'tuple'>

Accessing Tuple Elements

Tuple elements are accessed using index positions. 

fruits = ("Apple", "Orange", "Mango")

print(fruits[0])
print(fruits[1])
print(fruits[2])

Output

Apple
Orange
Mango

Negative Indexing

fruits = ("Apple", "Orange", "Mango")

print(fruits[-1])
print(fruits[-2])

Output

Mango
Orange

Tuple Slicing

numbers = (10,20,30,40,50,60)

print(numbers[1:4])
print(numbers[:3])
print(numbers[3:])

Output

(20, 30, 40)
(10, 20, 30)
(40, 50, 60)

Traversing a Tuple

numbers = (10,20,30,40)

for item in numbers:
    print(item)

Output

10
20
30
40

Tuple Functions

Function Purpose
len() Returns number of elements
max() Returns largest element
min() Returns smallest element
sum() Returns total of numeric elements 
numbers = (10,20,30,40)

print(len(numbers))
print(max(numbers))
print(min(numbers))
print(sum(numbers))

Output

4
40
10
100

Tuple Methods

Method Description
count() Counts occurrences of an element
index() Returns index position of an element

count()

numbers = (10,20,10,30,10)

print(numbers.count(10))

Output

3

index()

numbers = (10,20,30,40)

print(numbers.index(30))

Output

2

Tuple Concatenation

Two tuples can be joined using the + operator. 

t1 = (1,2,3)
t2 = (4,5,6)

t3 = t1 + t2

print(t3)

Output

(1, 2, 3, 4, 5, 6)

Tuple Repetition

t = ("Python",)

print(t * 3)

Output

('Python', 'Python', 'Python')

Tuple Packing and Unpacking

Packing

student = ("Arun", 17, 95)

Unpacking

student = ("Arun", 17, 95)

name, age, mark = student

print(name)
print(age)
print(mark)

Output

Arun
17
95

Difference Between List and Tuple

List Tuple
Mutable Immutable
[ ] ( )
Many methods available Limited methods
Consumes more memory Consumes less memory
