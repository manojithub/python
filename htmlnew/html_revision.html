17. Quick Revision and Exam Guide

Final revision of important tags, attributes, differences and question patterns.

Tag checklist

HTML, HEAD, TITLE, BODY, H1-H6, P, BR, HR, CENTER, B, I, U, S, BIG, SMALL, STRONG, EM, SUB, SUP, BLOCKQUOTE, Q, PRE, ADDRESS, MARQUEE, DIV, FONT, IMG, A, EMBED, UL, OL, DL, LI, DT, DD, TABLE, TR, TH, TD, CAPTION, FRAMESET, FRAME, NOFRAMES, FORM, INPUT, TEXTAREA, SELECT, OPTION, FIELDSET, LEGEND

Important differences

TopicDifference
Container / EmptyContainer has opening and closing tags; empty tag does not enclose a section.
UL / OLUnordered/bulleted vs ordered/numbered.
TH / TDHeading cell vs data cell.
Cellspacing / CellpaddingBetween cells vs between content and cell border.
Rowspan / ColspanSpans rows vs spans columns.
Radio / CheckboxOne choice from related alternatives vs one or more choices.
Text / TextareaSingle line vs multiple lines.

Frequently asked questions

  1. Who developed HTML?
  2. Name the two main sections of an HTML document.
  3. Compare container and empty tags.
  4. List IMG and FONT attributes.
  5. Explain internal linking.
  6. Differentiate Cellspacing and Cellpadding.
  7. Explain Rowspan and Colspan.
  8. Differentiate radio button and checkbox.
  9. Explain Action and Method in FORM.
  10. Write an HTML program for a list, table, frameset or form.
Exam method: Understand the output, identify the main tags, write the document structure, add attributes, close container tags and verify filenames/paths.
