HTML Quick Revision

Important textbook points for examination preparation.

Must-know tags

HTML, HEAD, TITLE, BODY, H1–H6, P, BR, HR, CENTER, B, I, U, S, BIG, SMALL, STRONG, EM, SUB, SUP, BLOCKQUOTE, Q, PRE, ADDRESS, MARQUEE, DIV, FONT, IMG, A, EMBED, UL, OL, DL, LI, DT, DD, TABLE, TR, TH, TD, CAPTION, FRAMESET, FRAME, NOFRAMES, FORM, INPUT

Important differences

  • Container vs empty tags
  • UL vs OL
  • TD vs TH
  • Cellspacing vs Cellpadding
  • Text vs Textarea
  • Internal vs external hyperlink
  • FRAMESET vs FRAME

Important attributes

  • A: Href, Name, Target
  • IMG: Src, Width, Height, Vspace, Hspace
  • FONT: Color, Face, Size
  • TABLE: Border, Bordercolor, Align, Bgcolor, Background, Cellspacing, Cellpadding, Width, Height, Frame
  • FRAME: Src, Scrolling, Noresize, Marginwidth, Marginheight, Name
  • FORM: Action, Method, Target
  • INPUT: Type
Final tip: Practise complete HTML programs. The textbook assessment includes code correction, output prediction, lists, hyperlinks, tables, frames and forms.
