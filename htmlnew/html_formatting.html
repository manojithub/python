5. Text Formatting Tags

Complete explanation of the formatting tags mentioned in the textbook, their purposes and examples.

Text formatting tags

TagPurposeClosing tag?Example
BBold textYes<B>Bold</B>
IItalic textYes<I>Italic</I>
UUnderlineYes<U>Underline</U>
S / STRIKEStrike-through textYes<S>Old</S>
BIGLarger textYes<BIG>Large</BIG>
SMALLSmaller textYes<SMALL>Small</SMALL>
STRONGStrong importance/bold appearanceYes<STRONG>Important</STRONG>
EMEmphasis/italic appearanceYes<EM>Important</EM>
SUBSubscriptYesH<SUB>2</SUB>O
SUPSuperscriptYesx<SUP>2</SUP>
BLOCKQUOTEIndents a quotationYes<BLOCKQUOTE>...</BLOCKQUOTE>
QShort quotationYes<Q>...</Q>
PREPreserves entered spacing/new linesYes<PRE>...</PRE>
ADDRESSContact informationYes<ADDRESS>...</ADDRESS>
MARQUEEScrolling/moving text in textbook examplesYes<MARQUEE>Notice</MARQUEE>
DIVGroups a block of contentYes<DIV>...</DIV>
FONTFont appearance in textbook examplesYes<FONT Size="5">Text</FONT>

FONT attributes

AttributePurpose
SizeControls text size in the textbook examples
ColorControls font colour in the textbook treatment
FaceSpecifies font face/typeface when supported
Modern HTML note: FONT and MARQUEE are legacy tags. Learn them because they occur in the syllabus/textbook, but use CSS for new websites.
