16. Textbook-Style HTML Practicals

Practice complete programs based on the textbook exercises.

Practice set

  1. Create a Kerala district page with a heading, paragraph using formatting tags and a tourist-place list.
  2. Create a school page with a paragraph, postal address and five co-curricular activities.
  3. Display Computer Components using nested lists for Hardware and Software.
  4. Create an Onam page with an attractive heading, Vallam Kali background and internal links to two traditional events.
  5. Create HSS and HS pages and a frameset page with navigation in one frame and content in another.
  6. Create the Road Accidents in Kerala 2012–2014 table and provide an external link.
  7. Create the Best Student Award application form using text, radio, select and checkbox controls.

Recommended practice order

Structure → formatting → images → lists → links → tables → frames → forms.

Do not skip coding practice. The textbook assessment includes error correction, list construction, hyperlinks, tables, frames and forms.
