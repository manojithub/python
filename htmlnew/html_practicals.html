17. HTML Practical Programs

Step-by-step Plus Two practical exercises with editable Try It Yourself examples.

How to approach an HTML practical

  1. Read the required output carefully.
  2. Identify the tags needed: heading, paragraph, list, image, table, link or form.
  3. Write the basic HTML structure first.
  4. Add tags one section at a time.
  5. Check every opening/closing container tag.
  6. Test the page in a browser.
