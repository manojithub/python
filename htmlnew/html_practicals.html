PLUS TWO COMPUTER SCIENCE

HTML Practicals — Textbook Practice

Practice tasks based on the exercises in the textbook.

1. District page: Heading, three-sentence paragraph using formatting tags/attributes and tourist-place list.
2. School page: Heading, paragraph and five co-curricular activities such as NCC, NSS and clubs.
3. Computer components: Display Hardware and Software using nested lists.
4. Onam page: Attractive heading, Vallam Kali background image and internal links to traditional events.
5. Frames: HSS and HS pages with links in one frame and the selected page in another.
6. Table + external link: Create the Road Accidents in Kerala table and provide an external link.
7. Application form: Create the Best Student Award form using text, radio, select and checkbox controls.

Practice order

  1. Basic document
  2. Formatting and images
  3. Lists
  4. Links
  5. Tables
  6. Frames
  7. Forms
