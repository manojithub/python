List family

UL + LI creates an unordered list, OL + LI creates an ordered list, and DL + DT + DD creates a description list. The textbook specifically asks students to remember UL attributes, OL Type values and Start, and nested-list coding.

Form family

FORM contains form controls. The textbook covers INPUT types, TEXTAREA, SELECT, OPTION, FIELDSET and LEGEND. fileciteturn19file0L22-L68

Table family

TABLE works with TR, TH and TD, while CAPTION provides the table title. Table attributes include border, alignment, spacing, padding, rowspan and colspan.

Frame family

FRAMESET partitions the browser window; FRAME defines an individual frame; NOFRAMES provides alternative content. The textbook also explains nested framesets and targeting a named frame.

HTML5 family

The textbook overview introduces HTML5 and lists newer semantic and multimedia elements such as VIDEO, AUDIO, CANVAS, HEADER, FOOTER, ARTICLE and SECTION.
