5.1 Lists in HTML

Unordered, ordered, definition and nested lists.

Three kinds of lists

The textbook identifies unordered, ordered and definition lists.

Unordered list

<UL>
<LI>RAM</LI>
<LI>Hard Disk</LI>
<LI>Processor</LI>
</UL>

Disc, Square and Circle are described as Type values for unordered lists.

Ordered list

<OL>
<LI>Registers</LI>
<LI>Cache</LI>
<LI>RAM</LI>
</OL>

Definition list

<DL>
<DT>Spam</DT>
<DD>Unsolicited e-mail.</DD>
<DT>Phishing</DT>
<DD>An attempt to obtain sensitive information.</DD>
</DL>

Nested lists

<OL>
<LI>Input Devices</LI>
<UL>
<LI>Keyboard</LI>
<LI>Mouse</LI>
</UL>
</OL>
