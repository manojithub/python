8. Lists in HTML

Create unordered, ordered, definition and nested lists.

Three list types

The textbook identifies unordered, ordered and definition lists.

UL — Unordered list

<UL>
<LI>RAM</LI>
<LI>Hard Disk</LI>
<LI>Processor</LI>
</UL>

UL displays bullets. The textbook discusses Type values Disc, Square and Circle.

<UL Type="Square">
<LI>Keyboard</LI>
<LI>Mouse</LI>
</UL>

OL — Ordered list

<OL>
<LI>Input</LI>
<LI>Processing</LI>
<LI>Output</LI>
</OL>

The textbook discusses numbering styles such as 1, A, a, I and i and starting from a specified value.

Definition list

<DL>
<DT>Spam</DT>
<DD>Unsolicited e-mail.</DD>
<DT>Phishing</DT>
<DD>An attempt to obtain sensitive information.</DD>
</DL>

Nested list

<OL>
<LI>Hardware
  <UL>
    <LI>Keyboard</LI>
    <LI>Monitor</LI>
  </UL>
</LI>
</OL>
