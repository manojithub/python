8. Lists – UL, OL, LI, DL, DT and DD

A complete lesson on unordered lists, ordered lists and description lists, including the textbook attributes, nested lists, syntax and exam-style practice.

1. <UL> – Unordered List

The <UL> tag creates an unordered list. The list items are written using <LI>. By default, browsers display bullets.

Syntax

<UL>
  <LI>Item 1</LI>
  <LI>Item 2</LI>
</UL>
Tag / AttributeMeaningExample
ULContainer for an unordered list.<UL>...</UL>
UL TypeSpecifies bullet style in the textbook treatment.disc, circle, square
LIDefines one list item.<LI>Kerala</LI>

Type attribute of UL

The textbook examples use disc, circle and square to control the bullet appearance.

<UL Type="square">
  <LI>HTML</LI>
  <LI>Python</LI>
</UL>

2. <OL> – Ordered List

The <OL> tag creates a numbered or ordered list. The Type attribute changes the numbering style and Start changes the starting number in the textbook examples.

<OL Type="A">
  <LI>Introduction</LI>
  <LI>HTML</LI>
  <LI>CSS</LI>
</OL>
AttributePurposeCommon textbook values
TypeChooses the numbering style.1, A, a, I, i
StartSpecifies the starting number/value.Start="6"

3. <LI> – List Item

<LI> represents an individual item within an ordered or unordered list. It may contain text, links, images and even another list.

4. <DL>, <DT> and <DD> – Description List

A description list is used to display terms and their descriptions.

<DL>
  <DT>HTML</DT>
  <DD>HyperText Markup Language</DD>
  <DT>CSS</DT>
  <DD>Cascading Style Sheets</DD>
</DL>
TagRole
DLContainer for the complete description list.
DTDefines the term or title.
DDDefines the description of that term.

5. Nested Lists

A list can be placed inside an <LI> to create sub-items. This is commonly used for questions such as Health Care → Baby Products → Toys and Dress.

<OL>
  <LI>Health Care</LI>
  <LI>Baby Products
    <UL Type="square">
      <LI>Toys</LI>
      <LI>Dress</LI>
    </UL>
  </LI>
</OL>
Exam tip: For ordered lists remember OL + LI; for unordered lists remember UL + LI; for description lists remember DL + DT + DD.

Practice Questions

Question 1

Write HTML code to create a list of your best friends.

Answer:
<UL Type="circle">
<LI>Akhil</LI>
<LI>Rahul</LI>
<LI>Anu</LI>
</UL>

Question 2

Write an ordered list using uppercase letters and start it from 6.

Answer:
<OL Type="A" Start="6">
<LI>HTML</LI>
<LI>CSS</LI>
</OL>
