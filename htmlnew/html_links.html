9. Hyperlinks – A Tag and Attributes

Learn internal, external, graphical and email links plus Href, Name and Target.

<A> hyperlink tag

The anchor tag creates a hyperlink. The destination is normally specified using Href.

AttributePurposeExample
HrefSpecifies destination URL/file<A Href="about.html">About</A>
NameCreates a named internal target/bookmark in textbook HTML<A Name="top">
TargetSpecifies where linked content should open; important with framesTarget="right_frame"

Types of links

  • Internal link: links to another place/page within the site.
  • External link: links to another website.
  • Graphical link: an image is placed inside A.
  • Email link: uses the mailto: protocol.
<A Href="mailto:student@example.com">Email me</A>
