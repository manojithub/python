9. Hyperlinks and Anchor Tag

Create external, internal, graphical and e-mail hyperlinks.

What is a hyperlink?

A hyperlink is text or an image that can be clicked to move to another document, website or section of the same document.

A — Anchor tag

<A Href="https://example.com">Visit Website</A>

Href is the main attribute of A and means hyper reference.

Internal link

<A Name="Introduction">INTRODUCTION</A>

<A Href="#Introduction">Go to Introduction</A>

The # symbol is essential when referring to the named section.

E-mail link

<A Href="mailto:slmanojkumar@gmail.com">Email Manojithub</A>

Graphical link

<A Href="home.html">
  <IMG Src="home-button.jpg">
</A>

Target

<A Href="bio.html" Target="right_frame">Biography</A>
Exam focus: Internal vs external linking; Href; Name; Target; mailto protocol.
