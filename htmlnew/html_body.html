3. BODY Tag and Page Attributes

Learn background, text and hyperlink colour attributes taught in the textbook.

BODY

The BODY section contains the content displayed in the browser.

<BODY Bgcolor="yellow" Text="blue">
Welcome to my page.
</BODY>

Important attributes

AttributePurposeExample
BgcolorBackground colourBgcolor="yellow"
TextDefault text colourText="blue"
LinkUnvisited link colourLink="green"
AlinkActive link colourAlink="red"
VlinkVisited link colourVlink="purple"
BackgroundBackground imageBackground="school.jpg"

Complete example

<BODY Bgcolor="#E6F4EA" Text="#222222" Link="green" Alink="red" Vlink="purple">
<H1>My School</H1>
<A Href="about.html">About Us</A>
</BODY>
Modern web note: These presentation attributes are included because they are in the textbook. Modern websites normally use CSS for styling.
