3. BODY Tag and Attributes

Detailed explanation of BODY and every BODY attribute listed in the Plus Two textbook.

<BODY> tag

The textbook introduces BODY attributes for controlling page background, text and hyperlink colours.

AttributePurposeExample
BgcolorSets background colour<BODY Bgcolor="yellow">
TextSets normal text colourText="blue"
LinkSets colour of an unvisited linkLink="green"
AlinkSets colour while a link is being activatedAlink="red"
VlinkSets colour of a visited linkVlink="purple"
BackgroundUses an image as page backgroundBackground="bg.jpg"
Exam note: These BODY attributes are part of the textbook's HTML treatment. In modern web development, CSS is normally preferred for page styling.
