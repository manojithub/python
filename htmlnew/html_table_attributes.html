12. Table Alignment, Rowspan and Colspan

Learn row/cell attributes and combine cells horizontally and vertically.

TR attributes

The textbook discusses Align, Valign and Bgcolor for rows.

<TR Bgcolor="yellow" Align="right" Valign="middle">
  <TH>Total</TH>
  <TD>159</TD>
</TR>

TH and TD

Both can use Align, Valign, Bgcolor, Colspan and Rowspan. The textbook notes center as the default horizontal alignment for TH and left for TD.

Colspan

Colspan specifies how many columns a cell occupies.

<TH Colspan="3">Student Information</TH>

Rowspan

Rowspan specifies how many rows a cell occupies.

<TD Rowspan="4">Computer Science</TD>
Memory trick: COLspan → across columns. ROWspan → down rows.

Textbook-style example

<TABLE Border="1" Cellspacing="3" Cellpadding="5">
<TR><TH Colspan="3">Student Details</TH></TR>
<TR><TH>Name</TH><TH>Class</TH><TH>Grade</TH></TR>
<TR><TD>Anu</TD><TD>XII</TD><TD>A+</TD></TR>
</TABLE>
