18. HTML Exam Question Bank

Plus Two exam-oriented questions, answers, error correction and coding practice based on the textbook.

Textbook-style short questions

QuestionAnswer / key point
What is HTML?HyperText Markup Language; used to create and organise web pages.
Name two empty tags.BR, HR, IMG (among the textbook examples).
How many heading levels are available?Six: H1 to H6.
Which attribute specifies a link destination?Href of A tag.
Which attribute opens a linked page in a specified frame?Target.
Differentiate Cellspacing and Cellpadding.Cellspacing is between cells; cellpadding is space between cell content and its border.
What are the main FORM attributes?Action and Method; Target is also used in the textbook.
Which tag groups form controls?FIELDSET.
Which tag gives a FIELDSET caption?LEGEND.
Which tag partitions a browser window into frames?FRAMESET.
What is nested frameset?A FRAMESET placed within another FRAMESET.
What is NOFRAMES used for?Alternative content when frames are not supported.

Find the error

<UL Type="i" Start="3">

Why is it wrong? Type/Start combination belongs to ordered-list numbering concepts; choose the correct list tag and attributes for the required output.

<IMG Src="Myschool.jpg" Size="50">

Correction: The textbook image attributes include Width and Height rather than a Size attribute.
