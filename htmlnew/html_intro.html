1. Introduction to HTML

Understand HTML, tags, container tags, empty tags and attributes before writing your first webpage.

What is HTML?

HTML stands for HyperText Markup Language. It is used to create and organise the contents of web pages. A browser interprets HTML tags and displays the page.

Tags

HTML tags are commands enclosed in angle brackets. The textbook notes that HTML tags are not case-sensitive.

ConceptMeaningExample
TagCommand used to format or organise page content<P>
Container tagHas opening and closing tags<P>...</P>
Empty tagDoes not require a closing tag<BR>
AttributeExtra information supplied in an opening tagAlign="center"

Attributes

Attributes provide additional information such as colour, measurement, location or alignment. Values may be written in single or double quotes.
