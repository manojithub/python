1. Introduction to HTML

Learn the basic idea of HTML, tags, container tags, empty tags and attributes.

What is HTML?

HTML means HyperText Markup Language. It is used to describe and organise the content of web pages. A browser interprets HTML instructions and displays the result.

HTML tags

Tags are commands enclosed in angle brackets < and >. They tell the browser how content should be organised.

<H1>My School</H1>
<P>Welcome to our school website.</P>

Container tags

A container tag has an opening tag and a closing tag. The closing tag has a forward slash.

<P>This is a paragraph.</P>

Empty tags

Empty tags do not enclose a section. Examples in the textbook include <BR>, <HR> and <IMG>.

Attributes

An attribute provides additional information such as colour, measurement, alignment or location. It normally appears in the opening tag.

<H1 Align="center">Welcome</H1>
