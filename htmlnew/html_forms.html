14. Forms – FORM, INPUT, TEXTAREA, SELECT, OPTION, FIELDSET and LEGEND

The textbook uses Forms to collect information from a webpage viewer. This lesson covers the complete Form section with syntax, controls, attributes, examples and practice.

1. <FORM> tag

A <FORM> is a container for form controls. The textbook identifies Action, Method and Target as important attributes.

<FORM Action="login.php" Method="post" Target="_blank">
  ...form controls...
</FORM>
AttributePurpose
ActionSpecifies the URL of the form handler.
MethodSpecifies the method used to submit data, commonly GET or POST.
TargetSpecifies the window/frame in which the result is displayed, such as _blank, _self or a named frame.

<INPUT> tag and controls

<INPUT> is used for several single-line and button controls. The textbook examples include text, password, radio, checkbox, submit and reset controls.

TypeUseTypical attributes in textbook examples
textSingle-line text inputName, Size, Maxlength, Value
passwordPassword entryName, Size, Maxlength
radioSelect one option in a groupName, Value
checkboxSelect zero or more itemsName, Value
submitSubmit the formValue
resetClear/reset form controlsValue

Radio button vs Checkbox

Radio buttons are grouped through the same Name so that one alternative can be selected. Checkboxes are used where one or more items may be selected.

<TEXTAREA> tag

The textbook uses <TEXTAREA> for multi-line input such as an address. Its main attributes are Name, Rows and Cols.

<TEXTAREA Rows="5" Cols="25" Name="address">Address</TEXTAREA>

<SELECT> and <OPTION>

<SELECT> creates a selection box. <OPTION> entries are placed inside it. The textbook gives Name, Size and Multiple for SELECT, and Selected and Value for OPTION.

TagAttributeMeaning
SELECTNameName used when data is submitted.
SELECTSizeControls dropdown/list-box presentation; textbook notes Size=1 as a dropdown.
SELECTMultipleAllows multiple selections.
OPTIONSelectedIndicates default selection.
OPTIONValueValue submitted may differ from displayed text.

<FIELDSET> and <LEGEND>

<FIELDSET> groups related controls. <LEGEND> provides a caption for that group.

<FIELDSET>
  <LEGEND>Nationality</LEGEND>
  <SELECT Name="Nationality" Size="4">
    <OPTION Value="Indian" Selected>Indian</OPTION>
    <OPTION Value="British">British</OPTION>
  </SELECT>
</FIELDSET>
Textbook connection: The textbook's complete student form combines text, radio, checkbox, SELECT, FIELDSET, LEGEND, TEXTAREA, submit and reset controls in one FORM.

Practice Questions

Q1. What are the main attributes of FORM?

Answer: Action and Method are the main attributes described by the textbook; Target is also used to specify the result window/frame.

Q2. Differentiate between text control and textarea control.

Answer: Text input is a single-line control using INPUT Type="text", while TEXTAREA provides a multi-line text entry area.

Q3. Which tag groups data within a Form?

Answer: FIELDSET. LEGEND can be used to give the FIELDSET a caption.
