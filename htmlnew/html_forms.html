14. Forms — Complete Tutorial

Collect user input with FORM, INPUT, TEXTAREA, SELECT, OPTION, FIELDSET and LEGEND.

What is a form?

The textbook explains that forms collect data from the web page viewer for processing. A form contains a FORM container and controls such as text fields, textareas, menus, radio buttons and checkboxes.

FORM syntax

<FORM Action="process.php" Method="post" Target="_blank">
  ...controls...
</FORM>
AttributePurpose
ActionURL of the form handler.
MethodGET or POST method used to submit data.
TargetWindow/frame for the result.

Text and password

<INPUT Type="text" Name="firstname" Size="30" Maxlength="25">
<INPUT Type="password" Name="Psswd" Size="30" Maxlength="25">

Radio buttons

Radio buttons are used to select one option from a set of alternatives.

<INPUT Type="radio" Name="sex" Value="male"> Male
<INPUT Type="radio" Name="sex" Value="female"> Female

Checkboxes

Checkboxes can select one or more choices.

<INPUT Type="checkbox" Name="Hobby" Value="games"> Games
<INPUT Type="checkbox" Name="Hobby" Value="Reading"> Reading

TEXTAREA

<TEXTAREA Rows="5" Cols="25" Name="address">Address</TEXTAREA>

SELECT

<SELECT Name="Course" Size="3">
  <OPTION Value="CS" Selected>Computer Science</OPTION>
  <OPTION Value="Commerce">Commerce</OPTION>
</SELECT>

FIELDSET and LEGEND

<FIELDSET>
<LEGEND>Personal Details</LEGEND>
...
</FIELDSET>

Submit and reset

<INPUT Type="submit" Value="Submit">
<INPUT Type="reset" Value="Clear">
