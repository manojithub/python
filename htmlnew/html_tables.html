11. Tables — Complete Tutorial

Create tables using TABLE, TR, TH, TD, CAPTION and important attributes.

Table structure

<TABLE Border="1">
  <TR>
    <TH>Roll No</TH><TH>Name</TH>
  </TR>
  <TR>
    <TD>1</TD><TD>Anu</TD>
  </TR>
</TABLE>
TagPurpose
TABLECreates table.
TRCreates row.
THHeading cell.
TDData cell.
CAPTIONTable caption.

Important attributes

AttributeUse
BorderBorder thickness.
BordercolorBorder colour.
AlignTable alignment.
BgcolorBackground colour.
BackgroundBackground image.
CellspacingSpace between cells.
CellpaddingSpace between content and border.
Width/HeightTable dimensions.

Caption

<TABLE Border="1">
<CAPTION>Student Details</CAPTION>
...
</TABLE>
