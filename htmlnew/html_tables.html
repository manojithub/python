11. Tables – TABLE, TR, TH, TD and CAPTION

Learn table structure, cells, rows, headings, captions and spanning cells.

Basic table structure

A table is made from rows and cells. TABLE is the container, TR creates a row, TH creates a heading cell and TD creates a data cell. CAPTION provides a table title.

TagPurposeTypical syntax
TABLECreates the table<TABLE>...</TABLE>
TRTable row<TR>...</TR>
THHeading cell<TH>Heading</TH>
TDData cell<TD>Data</TD>
CAPTIONCaption/title for table<CAPTION>Marks</CAPTION>

Rowspan and Colspan

Rowspan combines cells vertically. Colspan combines cells horizontally.
