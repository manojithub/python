6. Images with IMG

Insert images and understand Src, Alt, Width, Height, Vspace and Hspace.

IMG syntax

<IMG Src="school.jpg">

IMG inserts an image. Src specifies the image file.

Full syntax

<IMG Src="school.jpg" Alt="Our school" Width="500" Height="300" Vspace="10" Hspace="10">
AttributePurpose
SrcImage file/location.
AltAlternative text/information.
WidthImage width.
HeightImage height.
VspaceVertical space around image.
HspaceHorizontal space around image.

Example

<H2>Our School</H2>
<IMG Src="school.jpg" Alt="Photograph of our school" Width="500" Height="300">
Exam focus: The main attribute used to insert an image file is Src. Know the purpose of Alt.
