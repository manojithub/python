HTML Document Structure, Tags & Attributes

The foundation of an HTML document.

Basic structure

<HTML>
<HEAD>
<TITLE>My First Web Page</TITLE>
</HEAD>
<BODY>
Hello, Welcome to the world of web pages!
</BODY>
</HTML>

The textbook identifies the HTML document as having a HEAD section and a BODY section. TITLE is placed in HEAD and visible content is placed in BODY.

Container and empty tags

TypeMeaningExamples
ContainerOpening and closing tags<HTML>...</HTML>
EmptyNo closing tag required<BR>, <HR>, <IMG>

Attributes

Attributes provide additional information such as colour, measurement, location or alignment and normally appear in the opening tag.

Exam tip: Distinguish tag, attribute, container tag and empty tag with examples.
