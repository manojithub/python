2. HTML Document Structure

Learn the complete basic structure of an HTML document and the role of HTML, HEAD, TITLE and BODY.

Basic HTML document

<HTML>
<HEAD>
<TITLE>Page title</TITLE>
</HEAD>
<BODY>
Page content
</BODY>
</HTML>
TagPurposeImportant points
HTMLRoot/container of the documentOpening and closing tags surround the document.
HEADContains document informationTITLE is placed inside HEAD.
TITLESets the browser/page titleContainer tag.
BODYContains visible page contentText, images, lists, tables etc. are placed here.

<HTML> Tag Attributes

AttributeValueImportant points
dirrtl/ltrdirection of the text.
langen,hi,ar,el etcSpecify language used.
enEnglish
elGreek
esSpanish
hiHindi
arArabic
deFrench

Why structure matters

The browser uses the document structure to understand which information belongs to the head and which content should be displayed in the body.
