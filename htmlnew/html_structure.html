2. Basic HTML Document Structure

Build a complete HTML page and understand HTML, HEAD, TITLE and BODY.

Standard structure

<HTML>
<HEAD>
<TITLE>My First Web Page</TITLE>
</HEAD>
<BODY>
Hello, Welcome to the world of web pages!
</BODY>
</HTML>

Line-by-line explanation

CodeExplanation
<HTML>Starts the HTML document.
<HEAD>Contains document information.
<TITLE>Sets the browser page title.
<BODY>Contains content shown in the page.
</HTML>Ends the document.

Try it yourself

Textbook point: HTML is not case sensitive. The textbook uses uppercase tags and sentence-case attributes for readability.
