6. Marquee –Tag and Attributes

Learn Marquee Tag and all its attributes covered in the textbook.

<MARQUEE> tag

The <marquee> tag is used for creating scrollable text or images within a web page.But this tag has been deprecated in HTML 5..

AttributePurposeExample
Width,HeightSpecifies width/height for the marqueewidth="50" or height="20"
Directionprovides the directionin which marquee to scrolldirection="left"/"right"
Scrolldelayused for delaying each scroll jumpScrolldelay="2"
Scrollamountused for speeding the marqueeeScrollamount="3"
Behaviorspecify the type of marqueeescroll, slide,alternate
loopspecify number of times the marquee will looploop="infinite"/number
Bgcolorprovides background colour for marqueebgcolor="red"
VspaceVertical space around marqueeLVspace="10"
HspaceHorizontal space around marqueeHspace="10"

Syntax

<marquee direction="right" width="400" Height="250">
