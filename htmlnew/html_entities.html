7. HTML Entities and Comments

Learn special characters/entities and HTML comments with simple examples.

HTML entities

Entities are used when a character has a special meaning in HTML or when we need to display a character that may be interpreted as markup.

EntityDisplaysUse
&lt;<Display a less-than sign
&gt;>Display a greater-than sign
&amp;&Display ampersand
&nbsp;non-breaking spacePreserve an extra space
&quot;"Double quotation mark
&apos;'Single quotation mark
&trade;™Trademark
&copy;©Copyright
&reg;®Registered trademark

Comments

Comments are notes in HTML source code that are not displayed as page content.

<!-- This is a comment -->
