📖 Dictionaries in Python

Introduction to Dictionaries

A Dictionary is a collection of data stored in the form of key-value pairs.

Each key is unique and is used to access its corresponding value. Dictionaries are widely used for storing structured data such as student records, employee details and product information. 

student = {
    "name": "Arun",
    "age": 17,
    "mark": 95
}

print(student)

Output

{'name': 'Arun', 'age': 17, 'mark': 95}

Characteristics of Dictionaries

  • Dictionaries store data as key-value pairs.
  • Keys must be unique.
  • Values can be duplicated.
  • Dictionaries are mutable.
  • Dictionaries are enclosed within curly braces { }.
  • Elements are accessed using keys instead of indexes.

Creating a Dictionary

student = {
    "name": "Anu",
    "class": "XI",
    "mark": 98
}

print(student)

Accessing Dictionary Elements

Values are accessed using their keys. 

student = {
    "name": "Rahul",
    "age": 17,
    "mark": 90
}

print(student["name"])
print(student["mark"])

Output

Rahul
90

Using get() Method

The get() method safely retrieves values from a dictionary. 

student = {
    "name": "Arun",
    "mark": 95
}

print(student.get("name"))

Output

Arun

Adding New Elements

student = {
    "name": "Anu",
    "mark": 90
}

student["age"] = 17

print(student)

Output

{'name': 'Anu', 'mark': 90, 'age': 17}

Modifying Values

student = {
    "name": "Anu",
    "mark": 90
}

student["mark"] = 95

print(student)

Output

{'name': 'Anu', 'mark': 95}

Removing Elements

student = {
    "name": "Anu",
    "mark": 90,
    "age": 17
}

del student["age"]

print(student)

Output

{'name': 'Anu', 'mark': 90}

Dictionary Functions

Function Purpose
len() Returns number of key-value pairs
type() Returns data type
str() Converts dictionary to string 
student = {
    "name": "Arun",
    "mark": 95
}

print(len(student))
print(type(student))

Output

2
<class 'dict'>

Important Dictionary Methods

Method Description
keys() Returns all keys
values() Returns all values
items() Returns key-value pairs
update() Updates dictionary
pop() Removes specified key
clear() Removes all elements

keys()

student = {
    "name": "Arun",
    "mark": 95
}

print(student.keys())

Output

dict_keys(['name', 'mark'])

values()

student = {
    "name": "Arun",
    "mark": 95
}

print(student.values())

Output

dict_values(['Arun', 95])

items()

student = {
    "name": "Arun",
    "mark": 95
}

print(student.items())

Output

dict_items([('name', 'Arun'), ('mark', 95)])

Traversing a Dictionary

student = {
    "name": "Arun",
    "age": 17,
    "mark": 95
}

for key in student:
    print(key, ":", student[key])

Output

name : Arun
age : 17
mark : 95

Nested Dictionary

A dictionary inside another dictionary is called a nested dictionary. 

students = {
    "s1": {"name":"Arun", "mark":90},
    "s2": {"name":"Anu", "mark":95}
}

print(students["s1"]["name"])

Output

Arun

data = {
    "A": 10,
    "B": 20,
    "C": 30
}

for k, v in data.items():
    print(k, "=", v)

Program 3: Search a Key

student = {
    "name": "Arun",
    "age": 17,
    "mark": 95
}

key = input("Enter Key: ")

if key in student:
    print("Key Found")
else:
    print("Key Not Found")
