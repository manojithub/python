⌨ Input and Output in Python

Introduction

Every computer program needs a way to receive data from the user and display the results. In Python, this is achieved using Input and Output operations.

  • Input – Data entered by the user.
  • Output – Information displayed to the user.

Output Using print()

The print() function is used to display output on the screen. 

print("Hello World")

Output

Hello World

Printing Multiple Values

name = "Anu"
age = 17

print(name, age)

Output

Anu 17

Printing Messages and Variables

name = "Rahul"

print("Welcome", name)

Output

Welcome Rahul

Input Using input()

The input() function is used to accept data from the user through the keyboard. 

name = input("Enter your name: ")

print("Hello", name)

Sample Output

Enter your name: Arun
Hello Arun

How input() Works

  1. The program displays a message.
  2. The user enters data.
  3. The entered value is stored in a variable.
  4. The program processes the value.

Important Note

By default, the input() function stores data as a string. 

age = input("Enter Age: ")

print(type(age))

Output

<class 'str'>

Type Conversion

Type conversion is used to convert data from one type to another.

Function Purpose
int() Convert to Integer
float() Convert to Float
str() Convert to String

Using int()

age = int(input("Enter Age: "))

print(age)
print(type(age))

Sample Output

Enter Age: 17
17
<class 'int'>

Using float()

salary = float(input("Enter Salary: "))

print(salary)

Sample Output

Enter Salary: 25000.50
25000.5

Program: Addition of Two Numbers

num1 = int(input("Enter First Number: "))
num2 = int(input("Enter Second Number: "))

sum = num1 + num2

print("Sum =", sum)

Sample Output

Enter First Number: 10
Enter Second Number: 20
Sum = 30

Program Explanation

  1. Read first number using input().
  2. Convert it into integer using int().
  3. Read second number.
  4. Add the two numbers.
  5. Display the result using print().

Reading Multiple Inputs

name = input("Enter Name: ")
age = int(input("Enter Age: "))
mark = float(input("Enter Mark: "))

print(name)
print(age)
print(mark)

Formatted Output

Output can be formatted to make it more readable. 

name = "Anu"
mark = 95

print("Student Name:", name)
print("Mark:", mark)

Output

Student Name: Anu
Mark: 95

Using f-Strings

F-strings provide a modern and convenient way to format output. 

name = "Arun"
mark = 98

print(f"{name} scored {mark} marks")

Output

Arun scored 98 marks

Real-Life Example

name = input("Enter Student Name: ")
mark1 = int(input("Enter Mark 1: "))
mark2 = int(input("Enter Mark 2: "))

total = mark1 + mark2

print("Student:", name)
print("Total Marks:", total)

Sample Output

Enter Student Name: Rahul
Enter Mark 1: 75
Enter Mark 2: 80

Student: Rahul
Total Marks: 155

Common Errors

  • Forgetting to convert input values before calculations.
  • Using int() on non-numeric values.
  • Missing quotation marks in print().
  • Incorrect indentation.

📚 Exam Tips

  • print() is used for output.
  • input() is used for input.
  • input() returns a string by default.
  • Use int() and float() for numeric calculations.
  • Practice writing programs using user input.
