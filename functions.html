📁 Functions in Python

Introduction to Functions

A Function is a block of reusable code designed to perform a specific task. Functions help reduce code repetition, improve readability and make programs easier to maintain.

Python provides built-in functions such as print(), input(), len() and also allows users to create their own functions. 

print("Welcome to Python")
print(len("Python"))

Advantages of Functions

  • Reduces repetition of code.
  • Improves readability.
  • Makes debugging easier.
  • Supports modular programming.
  • Allows code reusability.

Defining a Function

Syntax

def function_name():
    statements
def greet():
    print("Hello Python")

greet()

Output

Hello Python

Components of a Function

  • def – Keyword used to define a function.
  • Function Name – Name given to the function.
  • Parameters – Values received by the function.
  • Function Body – Statements inside the function.
  • Return Statement – Returns a value.

Function Call

A function executes only when it is called. 

def message():
    print("Function Executed")

message()

Output

Function Executed

Types of Functions

  1. Built-in Functions
  2. User Defined Functions

Built-in Functions

numbers = [10,20,30]

print(len(numbers))
print(max(numbers))
print(min(numbers))

Output

3
30
10

User Defined Functions

def display():
    print("Welcome to Python")

display()

Functions with Parameters

Parameters allow values to be passed into a function. 

def greet(name):
    print("Hello", name)

greet("Arun")

Output

Hello Arun

Functions with Multiple Parameters

def add(a, b):
    print(a + b)

add(10, 20)

Output

30

Arguments and Parameters

Parameter Argument
Variable in function definition Actual value passed
def add(a,b) add(10,20)

Function Returning a Value

The return statement sends a value back to the caller. 

def square(n):
    return n * n

result = square(5)

print(result)

Output

25

Function Without Return Statement

def display():
    print("Python")

display()

Actual and Formal Arguments

def add(a, b):   # Formal Arguments
    print(a + b)

add(10, 20)      # Actual Arguments

Scope of Variables

Scope refers to the area where a variable can be accessed.

Local Variable

def demo():
    x = 10
    print(x)

demo()

Global Variable

x = 100

def demo():
    print(x)

demo()

Output

100

Recursive Functions

A recursive function is a function that calls itself. 

def countdown(n):

    if n > 0:
        print(n)
        countdown(n-1)

countdown(5)

Output

5
4
3
2
1

Lambda Functions

Lambda functions are small anonymous functions created using the lambda keyword. 

square = lambda x: x * x

print(square(6))

Output

36

Program 1: Find Sum Using Function

def add(a, b):
    return a + b

result = add(10, 20)

print("Sum =", result)

Program 2: Find Largest Number

def largest(a, b):

    if a > b:
        return a
    else:
        return b

print(largest(50, 30))

Output

50

Program 3: Calculate Factorial

def factorial(n):

    fact = 1

    for i in range(1, n+1):
        fact *= i

    return fact

print(factorial(5))

Output

120

Program 4: Check Even or Odd

def check(num):

    if num % 2 == 0:
        return "Even"
    else:
        return "Odd"

print(check(12))

Output

Even
