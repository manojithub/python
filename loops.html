🔁 Loops in Python

Introduction to Loops

In programming, a loop is used to execute a block of code repeatedly. Loops help reduce the amount of code and make programs more efficient.

For example, instead of writing the same print statement ten times, we can use a loop to repeat it automatically. 

print("Python")
print("Python")
print("Python")
print("Python")
print("Python")

The above code can be replaced by a loop.

Types of Loops in Python

Loop Type Purpose
while loop Repeats while a condition is True
for loop Repeats for a fixed sequence of values
Nested Loop A loop inside another loop

1️⃣ The while Loop

The while loop executes a block of code repeatedly as long as the specified condition remains True.

Syntax

while condition:
    statement

Example 1: Print Numbers 1 to 5

i = 1

while i <= 5:
    print(i)
    i = i + 1

Output

1
2
3
4
5

Dry Run Table

i Condition Output
1 True 1
2 True 2
3 True 3
4 True 4
5 True 5

Infinite Loop

If the loop condition never becomes False, the loop runs forever. This is called an Infinite Loop. 

while True:
    print("Hello")

2️⃣ The for Loop

The for loop is used to iterate through a sequence such as a range, string, list or tuple.

Syntax

for variable in sequence:
    statement

Example 1: Print Numbers 1 to 5

for i in range(1, 6):
    print(i)

Output

1
2
3
4
5

Understanding range()

Function Output
range(5) 0,1,2,3,4
range(1,5) 1,2,3,4
range(1,10,2) 1,3,5,7,9

Example 2: Print Even Numbers

for i in range(2, 11, 2):
    print(i)

Output

2
4
6
8
10

Example 3: Print Characters of a String

name = "PYTHON"

for ch in name:
    print(ch)

Output

P
Y
T
H
O
N

3️⃣ Nested Loops

A nested loop is a loop inside another loop.

Syntax

for i in range(3):

    for j in range(2):
        statement

Example

for i in range(3):

    for j in range(2):
        print("*", end=" ")

    print()

Output

* *
* *
* *

Pattern Programs

Star Pattern

for i in range(1,6):

    for j in range(i):
        print("*", end=" ")

    print()

Output

*
* *
* * *
* * * *
* * * * *

4️⃣ break Statement

The break statement immediately terminates the loop. 

for i in range(1,11):

    if i == 6:
        break

    print(i)

Output

1
2
3
4
5

When i becomes 6, the loop stops completely.

5️⃣ continue Statement

The continue statement skips the current iteration and moves to the next iteration. 

for i in range(1,6):

    if i == 3:
        continue

    print(i)

Output

1
2
4
5

Number 3 is skipped.

6️⃣ pass Statement

The pass statement does nothing. It acts as a placeholder for future code. 

for i in range(5):

    if i == 3:
        pass

    print(i)

Output

0
1
2
3
4

Program 1: Sum of First 10 Numbers

sum = 0

for i in range(1,11):
    sum = sum + i

print("Sum =", sum)

Output

Sum = 55

Program 2: Multiplication Table

num = int(input("Enter Number: "))

for i in range(1,11):
    print(num, "x", i, "=", num*i)

Program 3: Factorial of a Number

n = int(input("Enter Number: "))

fact = 1

for i in range(1,n+1):
    fact = fact * i

print("Factorial =", fact)

Program 4: Reverse Counting

for i in range(10,0,-1):
    print(i)

📚 Exam Tips

  • for loop is sequence-based.
  • range(start, stop, step) is very important.
  • break exits the loop immediately.
  • continue skips the current iteration.
  • pass is a placeholder statement.
  • Factorial and multiplication table programs are frequently asked.
