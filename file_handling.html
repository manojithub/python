📂 File Handling in Python

Introduction to File Handling

File Handling is used to store data permanently in a file. Normally, data stored in variables is lost when a program ends. Files allow data to be saved and retrieved whenever needed.

Python provides built-in functions to create, read, write and update files.

Advantages of File Handling

  • Permanent storage of data.
  • Easy retrieval of information.
  • Supports large amounts of data.
  • Useful for record management.
  • Allows data sharing between programs.

Opening a File

Before performing any operation, a file must be opened using the open() function.

Syntax

file_object = open("filename","mode")

File Modes

Mode Description
r Read Mode
w Write Mode
a Append Mode
r+ Read and Write
w+ Write and Read
a+ Append and Read

Creating and Writing to a File

file = open("sample.txt","w")

file.write("Welcome to Python")

file.close()

Reading a File

file = open("sample.txt","r")

data = file.read()

print(data)

file.close()

Output

Welcome to Python

Appending Data to a File

file = open("sample.txt","a")

file.write("\nPython File Handling")

file.close()

Reading Line by Line

file = open("sample.txt","r")

for line in file:
    print(line)

file.close()

read(), readline() and readlines()

Method Purpose
read() Reads entire file
readline() Reads one line
readlines() Reads all lines into a list

Using readline()

file = open("sample.txt","r")

print(file.readline())

file.close()

Using readlines()

file = open("sample.txt","r")

lines = file.readlines()

print(lines)

file.close()

Closing a File

After completing operations, the file should be closed using close(). 

file.close()

Using with Statement

The with statement automatically closes the file. 

with open("sample.txt","r") as file:
    print(file.read())

File Pointer Functions

Function Purpose
tell() Returns current position
seek() Moves file pointer 
file = open("sample.txt","r")

print(file.tell())

file.close()

Output

0

Using seek()

file = open("sample.txt","r")

file.seek(5)

print(file.read())

file.close()

Program 1: Write Student Details

file = open("student.txt","w")

name = input("Enter Name: ")
mark = input("Enter Mark: ")

file.write(name + "\n")
file.write(mark)

file.close()

print("Data Saved")

Program 2: Read Student Details

file = open("student.txt","r")

print(file.read())

file.close()

Program 3: Count Number of Lines

file = open("sample.txt","r")

count = len(file.readlines())

print("Lines =", count)

file.close()

Program 4: Count Words in a File

file = open("sample.txt","r")

data = file.read()

words = data.split()

print("Words =", len(words))

file.close()
