🧩 Modules in Python

Introduction to Modules

A Module is a file containing Python functions, variables and statements that can be reused in other programs.

Modules help organize large programs into smaller manageable files and promote code reusability. 

import math

print(math.sqrt(25))

Output

5.0

Advantages of Modules

  • Code Reusability
  • Easy Maintenance
  • Improved Readability
  • Reduces Program Size
  • Supports Modular Programming

Types of Modules

  1. Built-in Modules
  2. User Defined Modules

Built-in Modules

Python provides many ready-made modules such as:

  • math
  • random
  • datetime
  • os
  • statistics

Importing a Module

Syntax

import module_name

Example

import math

print(math.factorial(5))

Output

120

Import Specific Functions

from math import sqrt

print(sqrt(81))

Output

9.0

Import Multiple Functions

from math import sqrt, factorial

print(sqrt(64))
print(factorial(4))

Output

8.0
24

Using Alias Names

import math as m

print(m.sqrt(49))

Output

7.0

The math Module

Function Purpose
sqrt() Square Root
factorial() Factorial
pow() Power Calculation
ceil() Round Up
floor() Round Down 
import math

print(math.pow(2,3))
print(math.sqrt(16))

Output

8.0
4.0

The random Module

The random module generates random numbers and selections. 

import random

print(random.randint(1,10))

Output

Random number between 1 and 10

User Defined Modules

Programmers can create their own modules and use them in other programs.

Step 1: Create a Module

File: mymodule.py 
def add(a,b):
    return a+b

Step 2: Import the Module

import mymodule

print(mymodule.add(10,20))

Output

30

Program 1: Square Root Calculator

import math

num = int(input("Enter Number: "))

print("Square Root =", math.sqrt(num))

Program 2: Random Number Generator

import random

print(random.randint(1,100))

Program 3: Factorial Using math Module

import math

n = int(input("Enter Number: "))

print("Factorial =", math.factorial(n))
