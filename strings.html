📝 Strings in Python

Introduction to Strings

A string is a sequence of characters enclosed within single quotes (' '), double quotes (" "), or triple quotes (''' ''' or """ """). Strings are used to store text data such as names, addresses, messages, and sentences. 

name = "Python"
city = 'Kollam'

print(name)
print(city)

Output

Python
Kollam

Creating Strings

str1 = "Hello"
str2 = 'World'
str3 = """Python Programming"""

print(str1)
print(str2)
print(str3)

Characteristics of Strings

  • Strings are ordered collections of characters.
  • Strings are immutable (cannot be modified directly).
  • Each character has an index position.
  • Strings can contain letters, digits, symbols and spaces.

String Indexing

Each character in a string has a position called an index. Indexing starts from 0. 

word = "PYTHON"

Position : 0 1 2 3 4 5
Characters: P Y T H O N
word = "PYTHON"

print(word[0])
print(word[2])
print(word[5])

Output

P
T
N

Negative Indexing

Python also supports negative indexing. 

word = "PYTHON"

print(word[-1])
print(word[-2])

Output

N
O

String Slicing

Slicing is used to extract a portion of a string.

Syntax

string[start : stop : step]
word = "PYTHON"

print(word[0:3])
print(word[2:5])
print(word[:4])
print(word[3:])

Output

PYT
THO
PYTH
HON

String Concatenation

Concatenation means joining two or more strings using the + operator. 

first = "Hello"
second = "World"

result = first + " " + second

print(result)

Output

Hello World

String Repetition

The * operator is used to repeat strings. 

print("Python " * 3)

Output

Python Python Python

Membership Operators

Membership operators check whether a character or substring exists in a string. 

text = "Python Programming"

print("Python" in text)
print("Java" in text)

Output

True
False

Length of a String

The len() function returns the number of characters in a string. 

name = "Computer"

print(len(name))

Output

8

Common String Functions

Function Purpose
len() Returns length of string
max() Returns highest character
min() Returns lowest character
sorted() Sorts characters

String Methods

Method Description
upper() Convert to uppercase
lower() Convert to lowercase
title() Convert first letter of each word to uppercase
strip() Remove leading and trailing spaces
replace() Replace characters or words
find() Find position of a substring
count() Count occurrences

Examples of String Methods

text = "python programming"

print(text.upper())
print(text.title())

Output

PYTHON PROGRAMMING
Python Programming
text = "Python Programming"

print(text.replace("Python", "Java"))

Output

Java Programming
text = "banana"

print(text.count("a"))

Output

3

Traversing a String Using Loop

word = "PYTHON"

for ch in word:
    print(ch)

Output

P
Y
T
H
O
N

Program 1: Count Vowels

text = input("Enter a String: ")

count = 0

for ch in text.lower():

    if ch in "aeiou":
        count += 1

print("Number of Vowels =", count)

Program 2: Reverse a String

text = input("Enter a String: ")

print(text[::-1])

Program 3: Palindrome Check

word = input("Enter a Word: ")

if word == word[::-1]:
    print("Palindrome")
else:
    print("Not Palindrome")

Program 4: Count Characters

text = input("Enter a String: ")

print("Total Characters =", len(text))
