📋 Lists in Python

Introduction to Lists

A List is a collection of multiple values stored in a single variable. Lists are one of the most commonly used data structures in Python.

Unlike strings, lists can store different types of data such as integers, floats, strings and even other lists. 

numbers = [10, 20, 30, 40, 50]

print(numbers)

Output

[10, 20, 30, 40, 50]

Characteristics of Lists

  • Lists are ordered collections.
  • Lists are mutable (can be modified).
  • Lists allow duplicate values.
  • Lists can store different data types.
  • Lists are enclosed within square brackets [ ].

Creating Lists

list1 = [1, 2, 3, 4]
list2 = ["Apple", "Orange", "Mango"]
list3 = [10, "Python", 12.5]

print(list1)
print(list2)
print(list3)

Accessing List Elements

Each element in a list has an index position starting from 0. 

fruits = ["Apple", "Orange", "Mango"]

print(fruits[0])
print(fruits[1])
print(fruits[2])

Output

Apple
Orange
Mango

Negative Indexing

fruits = ["Apple", "Orange", "Mango"]

print(fruits[-1])
print(fruits[-2])

Output

Mango
Orange

List Slicing

Slicing extracts a portion of a list. 

numbers = [10,20,30,40,50,60]

print(numbers[1:4])
print(numbers[:3])
print(numbers[3:])

Output

[20, 30, 40]
[10, 20, 30]
[40, 50, 60]

Modifying List Elements

Lists are mutable, so their elements can be changed. 

numbers = [10,20,30]

numbers[1] = 50

print(numbers)

Output

[10, 50, 30]

Traversing a List

numbers = [10,20,30,40]

for item in numbers:
    print(item)

Output

10
20
30
40

Common List Functions

Function Purpose
len() Returns number of elements
max() Returns largest element
min() Returns smallest element
sum() Returns total of elements
sorted() Returns sorted list 
numbers = [5,10,15,20]

print(len(numbers))
print(max(numbers))
print(min(numbers))
print(sum(numbers))

Output

4
20
5
50

Important List Methods

Method Description
append() Add element at end
insert() Insert element at specified position
remove() Remove specified element
pop() Remove element by index
sort() Sort the list
reverse() Reverse the list
count() Count occurrences
index() Find position of element

append()

fruits = ["Apple", "Orange"]

fruits.append("Mango")

print(fruits)

Output

['Apple', 'Orange', 'Mango']

insert()

numbers = [10,20,30]

numbers.insert(1,15)

print(numbers)

Output

[10, 15, 20, 30]

remove()

numbers = [10,20,30]

numbers.remove(20)

print(numbers)

Output

[10, 30]

sort()

numbers = [40,10,50,20]

numbers.sort()

print(numbers)

Output

[10, 20, 40, 50]

reverse()

numbers = [10,20,30]

numbers.reverse()

print(numbers)

Output

[30, 20, 10]

Searching an Element

numbers = [10,20,30,40]

if 30 in numbers:
    print("Found")
else:
    print("Not Found")

Output

Found

Nested Lists

A list inside another list is called a Nested List. 

marks = [
    [75,80,90],
    [65,70,85]
]

print(marks[0])
print(marks[1])

Output

[75, 80, 90]
[65, 70, 85]

Program 1: Find Largest Number

numbers = [15,25,10,40,30]

print("Largest =", max(numbers))

Program 2: Calculate Sum of List Elements

numbers = [10,20,30,40]

print("Sum =", sum(numbers))

Program 3: Count Occurrences

numbers = [10,20,10,30,10]

print(numbers.count(10))

Output

3

Program 4: Linear Search

numbers = [5,10,15,20,25]

key = int(input("Enter Number to Search: "))

if key in numbers:
    print("Element Found")
else:
    print("Element Not Found")
