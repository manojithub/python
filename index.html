📘 Introduction to Python

What is Python?

Python is a high-level, interpreted, general-purpose programming language. It is one of the most popular programming languages in the world because of its simple syntax, readability, and powerful features.

Python allows programmers to develop applications quickly and efficiently. It is widely used in education, web development, artificial intelligence, data science, automation, and software development.

👨‍💻 History of Python

Python was developed by Guido van Rossum in the late 1980s and was officially released in 1991.

Python was designed to be simple, easy to learn, and highly productive.

Year Event
1989 Development Started
1991 First Official Release
2000 Python 2.0 Released
2008 Python 3.0 Released

⭐ Features of Python

  • Simple and Easy to Learn
  • Interpreted Language
  • Platform Independent
  • Object-Oriented
  • Open Source
  • Large Standard Library

1. Simple and Easy

Python uses simple English-like statements, making it ideal for beginners. 

print("Hello World")

2. Interpreted Language

Python programs are executed line by line by an interpreter. This makes debugging easier and development faster.

3. Platform Independent

Python programs can run on Windows, Linux, and macOS without major changes.

4. Object-Oriented

Python supports classes, objects, inheritance, and polymorphism.

5. Open Source

Python is freely available and can be used without licensing costs.

6. Large Standard Library

Python provides built-in modules for mathematics, file handling, networking, graphics, and database applications.

🌍 Applications of Python

🌐 Web Development

Used to build websites and web applications using Django and Flask.

🤖 Artificial Intelligence

Used in Machine Learning, Deep Learning, Robotics, and Chatbots.

📊 Data Science

Used for data analysis and visualization with Pandas and NumPy.

⚙ Automation

Automates repetitive tasks such as file management and reporting.

✅ Advantages of Python

  • Easy to Learn
  • Easy to Read
  • Free and Open Source
  • Platform Independent
  • Large Community Support
  • Huge Collection of Libraries
  • Suitable for Beginners

🔢 Variables and Data Types

What is a Variable?

A variable is a named memory location used to store data temporarily during the execution of a program. The value stored in a variable can be changed whenever required.

Variables help programmers store and manipulate information such as numbers, names, marks, and calculations.

Creating Variables in Python

In Python, a variable is created when a value is assigned to it using the assignment operator (=). 

x = 10
name = "Rahul"
marks = 95.5

Variable Assignment

Variable Value Stored
x 10
name Rahul
marks 95.5

Rules for Naming Variables

  • Variable names can contain letters, digits and underscore (_).
  • Variable names cannot begin with a digit.
  • Spaces are not allowed.
  • Python keywords cannot be used as variable names.
  • Variable names are case-sensitive.

Valid Variable Names

age = 17
student_name = "Anu"
totalMarks = 450
_count = 25

Invalid Variable Names

2age = 17        # Starts with digit
student name     # Contains space
class = 10       # Python keyword

Case Sensitivity

Python treats uppercase and lowercase letters differently. 

name = "Rahul"
Name = "Anu"

print(name)
print(Name)

Output

Rahul
Anu

What are Data Types?

A data type specifies the type of value stored in a variable. Python automatically identifies the data type based on the assigned value.

Common Data Types in Python

Data Type Description Example
int Integer values 25, 100, -8
float Decimal values 10.5, 98.25
str Text/String values "Python"
bool Logical values True, False

Integer (int)

Integer values are whole numbers without decimal points. 

age = 17
year = 2026

print(age)
print(year)

Float (float)

Float values contain decimal points. 

height = 5.8
price = 125.50

print(height)
print(price)

String (str)

Strings are sequences of characters enclosed within quotation marks. 

name = "Python"
city = "Kollam"

print(name)
print(city)

Boolean (bool)

Boolean values represent logical conditions. 

isStudent = True
isPassed = False

print(isStudent)
print(isPassed)

Checking Data Type Using type()

The type() function is used to identify the data type of a variable. 

x = 10
y = 12.5
name = "Python"

print(type(x))
print(type(y))
print(type(name))

Output

<class 'int'>
<class 'float'>
<class 'str'>

Type Conversion

Type conversion means changing one data type into another. 

x = "25"

num = int(x)

print(num)
print(type(num))

Output

25
<class 'int'>

Real-Life Example

student = "Arun"
age = 17
mark = 95.5
passed = True

print(student)
print(age)
print(mark)
print(passed)

Program Explanation

  1. student stores a string value.
  2. age stores an integer value.
  3. mark stores a float value.
  4. passed stores a boolean value.
  5. All values are displayed using print().

➕ Operators in Python

What is an Operator?

An operator is a special symbol used to perform operations on values and variables. Operators help us perform calculations, comparisons, logical decisions and assignments in a program. 

x = 10
y = 5

print(x + y)

In the above example, + is an operator used for addition.

Operator Type Purpose

Arithmetic operators are used to perform mathematical calculations.

Logical operators are used to combine two or more conditions.

⌨ Input and Output in Python

Introduction

Every computer program needs a way to receive data from the user and display the results. In Python, this is achieved using Input and Output operations.

  • Input – Data entered by the user.
  • Output – Information displayed to the user.

Output Using print()

The print() function is used to display output on the screen. 

print("Hello World")

Output

Hello World

Printing Multiple Values

name = "Anu"
age = 17

print(name, age)

Output

Anu 17

Printing Messages and Variables

name = "Rahul"

print("Welcome", name)

Output

Welcome Rahul

Input Using input()

The input() function is used to accept data from the user through the keyboard. 

name = input("Enter your name: ")

print("Hello", name)

Sample Output

Enter your name: Arun
Hello Arun

How input() Works

  1. The program displays a message.
  2. The user enters data.
  3. The entered value is stored in a variable.
  4. The program processes the value.

Important Note

By default, the input() function stores data as a string. 

age = input("Enter Age: ")

print(type(age))

🔀 Decision Making in Python

Introduction

In real life, we make decisions every day. For example:

  • If it rains, take an umbrella.
  • If marks are above 90, award Grade A.
  • If age is 18 or above, allow voting.

Similarly, Python programs use decision-making statements to execute different blocks of code based on conditions.

Conditional Statements in Python

Statement Purpose
if Execute code when a condition is true
if...else Choose between two alternatives
if...elif...else Choose from multiple alternatives
Nested if Use an if statement inside another if

1️⃣ The if Statement

The if statement executes a block of code only when the specified condition is true.

Syntax

if condition:
    statement

Example

age = 18

if age >= 18:
    print("Eligible to Vote")

Output

Eligible to Vote

Flowchart of if Statement


        Condition?
           |
      +----+----+
      |         |
    True      False
      |
 Execute
 Statement

2️⃣ The if...else Statement

The if...else statement is used when one action should be performed if the condition is true and another action if the condition is false.

Syntax

if condition:
    statement1
else:
    statement2

Example

num = int(input("Enter a Number: "))

if num % 2 == 0:
    print("Even Number")
else:
    print("Odd Number")

Sample Output

Enter a Number: 12
Even Number

Dry Run Table

num Condition (num % 2 == 0) Output
12 True Even Number
15 False Odd Number

3️⃣ The if...elif...else Ladder

When there are multiple conditions to check, Python uses the if...elif...else ladder.

Syntax

if condition1:
    statement1

elif condition2:
    statement2

elif condition3:
    statement3

else:
    statement4

Example: Grade Calculation

mark = int(input("Enter Mark: "))

if mark >= 90:
    print("Grade A")

elif mark >= 75:
    print("Grade B")

elif mark >= 50:
    print("Grade C")

else:
    print("Grade D")

Sample Output

Enter Mark: 82
Grade B

Flowchart of if-elif-else


     Condition1?
       /   \
    Yes    No
    |        |
 Statement1  Condition2?
             /      \
          Yes       No
          |          |
      Statement2   Else Block

4️⃣ Nested if Statement

A nested if statement is an if statement placed inside another if statement.

Syntax

if condition1:

    if condition2:
        statement

Example

age = int(input("Enter Age: "))

if age >= 18:

    if age <= 60:
        print("Eligible for Employment")

Sample Output

Enter Age: 25
Eligible for Employment

Program 1: Find Largest of Two Numbers

a = int(input("Enter First Number: "))
b = int(input("Enter Second Number: "))

if a > b:
    print("Largest =", a)
else:
    print("Largest =", b)

Program 2: Check Pass or Fail

mark = int(input("Enter Mark: "))

if mark >= 40:
    print("Pass")
else:
    print("Fail")

Program 3: Positive or Negative Number

num = int(input("Enter Number: "))

if num >= 0:
    print("Positive Number")
else:
    print("Negative Number")

Program 4: Voting Eligibility

age = int(input("Enter Age: "))

if age >= 18:
    print("Eligible to Vote")
else:
    print("Not Eligible to Vote")

Indentation in Python

Python uses indentation (spaces before statements) to identify code blocks. 

if True:
    print("Correct")

print("Program End")

Common Mistake

if True:
print("Wrong Indentation")

This will generate an IndentationError.

🔁 Loops in Python

Introduction to Loops

In programming, a loop is used to execute a block of code repeatedly. Loops help reduce the amount of code and make programs more efficient.

For example, instead of writing the same print statement ten times, we can use a loop to repeat it automatically. 

print("Python")
print("Python")
print("Python")
print("Python")
print("Python")

The above code can be replaced by a loop.

Types of Loops in Python

Loop Type Purpose
while loop Repeats while a condition is True
for loop Repeats for a fixed sequence of values
Nested Loop A loop inside another loop

1️⃣ The while Loop

The while loop executes a block of code repeatedly as long as the specified condition remains True.

Syntax

while condition:
    statement

Example 1: Print Numbers 1 to 5

i = 1

while i <= 5:
    print(i)
    i = i + 1

Output

2

5

Infinite Loop

If the loop condition never becomes False, the loop runs forever. This is called an Infinite Loop. 

while True:
    print("Hello")

2️⃣ The for Loop

The for loop is used to iterate through a sequence such as a range, string, list or tuple.

Syntax

for variable in sequence:
    statement

Example 1: Print Numbers 1 to 5

for i in range(1, 6):
    print(i)

Output

5

A nested loop is a loop inside another loop.

📝 Strings in Python

Introduction to Strings

A string is a sequence of characters enclosed within single quotes (' '), double quotes (" "), or triple quotes (''' ''' or """ """). Strings are used to store text data such as names, addresses, messages, and sentences. 

name = "Python"
city = 'Kollam'

print(name)
print(city)

Output

Python
Kollam

Creating Strings

str1 = "Hello"
str2 = 'World'
str3 = """Python Programming"""

print(str1)
print(str2)
print(str3)

Characteristics of Strings

  • Strings are ordered collections of characters.
  • Strings are immutable (cannot be modified directly).
  • Each character has an index position.
  • Strings can contain letters, digits, symbols and spaces.

String Indexing

Each character in a string has a position called an index. Indexing starts from 0. 

word = "PYTHON"

Position : 0 1 2 3 4 5
Characters: P Y T H O N
word = "PYTHON"

print(word[0])
print(word[2])
print(word[5])

Output

P
T
N

Negative Indexing

Python also supports negative indexing. 

word = "PYTHON"

print(word[-1])
print(word[-2])

Output

N

📂 File Handling in Python

Introduction to File Handling

File Handling is used to store data permanently in a file. Normally, data stored in variables is lost when a program ends. Files allow data to be saved and retrieved whenever needed.

Python provides built-in functions to create, read, write and update files.

Advantages of File Handling

  • Permanent storage of data.
  • Easy retrieval of information.
  • Supports large amounts of data.
  • Useful for record management.
  • Allows data sharing between programs.

Opening a File

Before performing any operation, a file must be opened using the open() function.

Syntax

file_object = open("filename","mode")

File Modes

Mode Description
r Read Mode
w Write Mode
a Append Mode
r+ Read and Write
w+ Write and Read
a+ Append and Read

Creating and Writing to a File

file = open("sample.txt","w")

file.write("Welcome to Python")

file.close()

Reading a File

file = open("sample.txt","r")

data = file.read()

print(data)

file.close()

Output

Welcome to Python

Appending Data to a File

file = open("sample.txt","a")

file.write("\nPython File Handling")

file.close()

Reading Line by Line

file = open("sample.txt","r")

for line in file:
    print(line)

file.close()

read(), readline() and readlines()

Method Purpose
read() Reads entire file
readline() Reads one line
readlines() Reads all lines into a list

Using readlines()

Closing a File

After completing operations, the file should be closed using close(). 

file.close()

with open("sample.txt","r") as file:
