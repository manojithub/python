➕ Operators in Python

What is an Operator?

An operator is a special symbol used to perform operations on values and variables. Operators help us perform calculations, comparisons, logical decisions and assignments in a program. 

x = 10
y = 5

print(x + y)

In the above example, + is an operator used for addition.

Types of Operators in Python

Operator Type Purpose
Arithmetic Operators Perform mathematical calculations
Relational Operators Compare values
Logical Operators Combine conditions
Assignment Operators Assign values to variables

1️⃣ Arithmetic Operators

Arithmetic operators are used to perform mathematical calculations.

Operator Operation Example
+ Addition 10 + 5 = 15
- Subtraction 10 - 5 = 5
* Multiplication 10 * 5 = 50
/ Division 10 / 5 = 2.0
% Modulus 10 % 3 = 1
// Floor Division 10 // 3 = 3
** Exponent 2 ** 3 = 8 
a = 20
b = 6

print("Addition =", a + b)
print("Subtraction =", a - b)
print("Multiplication =", a * b)
print("Division =", a / b)
print("Modulus =", a % b)

Output

Addition = 26
Subtraction = 14
Multiplication = 120
Division = 3.3333333333333335
Modulus = 2

2️⃣ Relational Operators

Relational operators compare two values and return either True or False.

Operator Meaning
== Equal To
!= Not Equal To
> Greater Than
< Less Than
>= Greater Than or Equal To
<= Less Than or Equal To 
x = 10
y = 20

print(x == y)
print(x != y)
print(x < y)
print(x > y)

Output

False
True
True
False

3️⃣ Logical Operators

Logical operators are used to combine two or more conditions.

Operator Description
and True if both conditions are true
or True if at least one condition is true
not Reverses the result 
a = 10
b = 20

print(a < b and b > 15)
print(a > b or b > 15)
print(not(a < b))

Output

True
True
False

Truth Table for AND Operator

A B A and B
True True True
True False False
False True False
False False False

4️⃣ Assignment Operators

Assignment operators are used to assign values to variables.

Operator Example Equivalent To
= x = 5 x = 5
+= x += 3 x = x + 3
-= x -= 3 x = x - 3
*= x *= 3 x = x * 3
/= x /= 3 x = x / 3 
x = 10

x += 5
print(x)

x *= 2
print(x)

Output

15
30

Operator Precedence

Operator precedence determines the order in which operations are performed.

Priority Operator
1 ()
2 **
3 *, /, //, %
4 +, -
5 Relational Operators
6 Logical Operators 
result = 10 + 5 * 2
print(result)

Output

20

Multiplication is performed before addition.

📚 Exam Tips

  • % gives the remainder after division.
  • // gives the integer quotient.
  • ** is used for exponentiation.
  • Relational operators return True or False.
  • Remember operator precedence for calculations.
