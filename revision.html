🐍 Python Basics

  • Developed by Guido van Rossum.
  • Easy to learn and platform independent.
  • Uses indentation instead of braces.

📦 Tuples

  • Ordered collection.
  • Immutable.
  • Uses () brackets.
t = (10,20,30)

🎯 Sets

  • Unordered collection.
  • No duplicate values.
  • Uses {} braces.
s = {10,20,30}

📖 Dictionary

  • Stores key-value pairs.
  • Uses {} braces.
  • Mutable collection.
student = {
    "name":"Arun",
    "mark":95
}
